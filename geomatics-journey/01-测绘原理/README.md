## 学习目标

1. 理解测量误差的本质与处理方法
2. 掌握大地测量的基本原理与坐标系统
3. 理解GNSS定位原理与误差模型
4. 掌握摄影测量成像几何与三维重建
5. 理解LiDAR测距原理与点云特性
6. 掌握坐标系统与投影变换

---

## 核心概念

- **误差理论**：最小二乘法、协方差传播、粗差探测
- **大地测量**：椭球参数、坐标变换原理
- **GNSS**：观测值与误差模型、坐标计算
- **摄影测量**：成像几何、三维重建原理
- **LiDAR**：测距原理、点云特性
- **空间参考系**：投影原理、七参数/四参数变换
